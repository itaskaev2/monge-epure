# Эпюр Монжа

Интерактивная страница: по координатам точки строит её проекции на П1, П2, П3
(комплексный чертёж) и показывает положение точки в октантах в 3D.

Открыть: https://itaskaev2.github.io/monge-epure/

- Оси как на листе: X вправо, Z вверх, Y горизонтальной проекции вниз, Y''' профильной проекции влево.
- Языки: русский, српски (ћирилица), srpski (latinica).
- Перенос глубины на П3 дугами (по умолчанию) или постоянной прямой k.
- Сетка 1 мм, масштаб колесом мыши или двумя пальцами, перетаскивание сдвигает лист.

Один файл `index.html`, без сборки и зависимостей (только шрифты Google Fonts).
